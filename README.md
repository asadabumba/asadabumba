### [EmbroideryAI-Research](https://github.com/asadabumba/EmbroideryAI-Research)

Research tooling for understanding native embroidery-design formats, deterministic Region5 reconstruction, and machine-state behavior. The longer-term goal is to automate embroidery design creation, potentially through direct file generation or an interface-controlling agent.

**Current scope:** independently implemented research models and documented findings; a complete native-format generator and autonomous agent are **not** claimed as finished.

### [AAPL-Return-Forecasting](https://github.com/asadabumba/AAPL-Return-Forecasting)
**Python · pandas · scikit-learn · time-series evaluation**

A reproducible ML experiment based on my first-year coursework. It compares linear regression, decision trees, random forests, and gradient boosting with simple baselines on historical Apple stock returns. The repository includes a chronological holdout, automated tests, plots, and a public edition of the coursework report.

**Key finding:** On the studied 2015–2024 dataset, the training-mean baseline achieved lower holdout MAE than all four ML models. Reporting this limitation is part of the project, not something to hide.
